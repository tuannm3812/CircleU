## Placement guidance

- Use as a bounded hero illustration above native content, not behind the writing editor. Keep titles and controls as native UI; these images contain no embedded text.
- Preserve the 2:1 composition with aspect fit initially. A portrait centre crop would remove the off-centre character; any crop needs a screen-specific review.
- Keep the Journal calendar header free of extra decoration. This Journal scene is intended for an introduction or empty state.
- Keep native symbols for interactive controls. These scenes are not icons, animation rigs or profile-avatar assets.
- Retain current font and colour tokens. Tonal variations in generated images do not redefine brand colours.
- Visual checks covered character identity, distinct composition, absence of text and obvious anatomy errors. Phone placement, larger text, dark mode and accessibility behaviour have not been tested.
