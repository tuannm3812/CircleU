# Preserved legacy Pingu originals

The JPEG originals below were moved out of the app's asset catalog on 24 October 2026. Each was an unassigned file beside the PNG selected by its image set, producing an Xcode asset warning. They are preserved byte-for-byte for provenance and later design review; runtime image sets continue using their existing PNGs.

- [Calm original](pingu-calm.jpg), formerly `Circleu/Assets.xcassets/PinguCalm.imageset/pingu-calm.jpg`.
- [Celebrating original](pingu-celebrating.jpg), formerly `Circleu/Assets.xcassets/PinguCelebrating.imageset/pingu-celebrating.jpg`.
- [Thinking original](pingu-thinking.jpg), formerly `Circleu/Assets.xcassets/PinguThinking.imageset/pingu-thinking.jpg`.

These are historical assets, separate from the accepted [current brand direction](../branding-guideline.md). No recompression, replacement or new design selection was performed.
