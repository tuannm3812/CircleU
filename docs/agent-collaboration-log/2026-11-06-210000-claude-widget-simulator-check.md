# Pocket widget: simulator check

6 November 2026, Claude. Follows [the widget entry](2026-11-06-190000-claude-pocket-widget.md), which listed a real widget as not covered.

A throwaway UI test drove the GuestReview build on the iPhone 18 Pro Simulator: Show on Home Screen, then the system widget gallery, then a placed medium widget. The widget showed the words saved by the app, so the shared keychain read works there, and tapping it opened the whole card with Take off Home Screen.

Still not covered: the same on the physical iPhone, whose signing differs, and redaction on locked screens. Access to iPhone Mirroring was not granted, so nothing was checked on the phone.
